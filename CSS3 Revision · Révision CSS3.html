1. The rule: WHO / WHAT / HOWLa règle : QUI / QUOI / COMMENT

h2 {
  color: red;
  text-align: center;
}

Aa Bb Cc

How it works, line by line

  • h2 = the selector (WHO?): every <h2> of the page.
  • { } = the block that contains all the declarations for that selector.
  • color: red; = a declaration: property color (WHAT changes?) + : + value red (HOW?) + ;.
  • text-align: center; = second declaration: centres the content of the title inside its line.

Why

  • CSS separates content (HTML) from presentation: change one rule and all the h2 of the site change.

Where to write CSS

  • External (best): <link rel="stylesheet" href="style.css"> in the <head>. One file for the whole site.
  • Internal: a <style> tag in the <head>. One page only; good for a quick test.
  • Inline: style="color:red;" on the tag. One element only; strongest but messy. No selector, no braces.
  • Priority: inline wins; internal vs external → the one written last wins. A .css file never contains <style>.
Trick: “:” between property and value, “;” after each declaration, “{ }” around the block. Comments: /* */ only. Decimals use a point: 1.5em.
Trap: a forgotten “;” cancels the NEXT declaration (the browser reads both lines as one wrong value).

Comment ça marche, ligne par ligne

  • h2 = le sélecteur (QUI ?) : tous les <h2> de la page.
  • { } = le bloc qui contient toutes les déclarations de ce sélecteur.
  • color: red; = une déclaration : propriété color (QUOI change ?) + : + valeur red (COMMENT ?) + ;.
  • text-align: center; = seconde déclaration : centre le contenu du titre dans sa ligne.

Pourquoi

  • CSS sépare le contenu (HTML) de la présentation : on change une règle et tous les h2 du site changent.

Où écrire le CSS

  • Externe (le mieux) : <link rel="stylesheet" href="style.css"> dans le <head>. Un seul fichier pour tout le site.
  • Interne : une balise <style> dans le <head>. Une seule page ; pratique pour un test rapide.
  • Inline (en ligne) : style="color:red;" sur la balise. Un seul élément ; le plus fort mais brouillon. Ni sélecteur, ni accolades.
  • Priorité : l’inline gagne ; interne contre externe → celui écrit en dernier gagne. Un fichier .css ne contient jamais <style>.
Astuce : « : » entre propriété et valeur, « ; » après chaque déclaration, « { } » autour du bloc. Commentaires : /* */ uniquement. Décimales avec un point : 1.5em.
Piège : un « ; » oublié annule la déclaration SUIVANTE (le navigateur lit les deux lignes comme une seule valeur fausse).

2. Colours and unitsCouleurs et unités

color: #FF0000;   color: rgb(255,0,0);   background: rgba(0,0,0,0.5);   font-size: 1.5em;
#FF0000#00FF00#0000FF#FFFF00#808080rgba .5#000000

How it works

  • Hex #RRGGBB: Red, Green, Blue, each from 00 (none) to FF (max). #FF0000 = red only. #FFFF00 = red + green = yellow. #808080 = half of everything = grey. Short form: #f00.
  • rgb(255,0,0): same thing in decimal, 0 to 255.
  • rgba(0,0,0,0.5): the 4th number is opacity, from 0 (invisible) to 1 (solid). Here: black at 50 %.
  • Absolute units (px, pt, cm, mm): fixed size. Relative units: em and % depend on the parent; rem on the root; vw/vh on the window.

Why

  • Relative units adapt to the screen and to the user’s font settings, so prefer them for layout.
Traps:
  • color: ff0000 → the # is missing.
  • margin: 10 → a unit is mandatory (10px); “16 px” with a space is also wrong.
  • Nested em multiply: parent 1.5em (24px), child 1.5em = 36px, not 24px.

Comment ça marche

  • Hexadécimal #RRVVBB : Rouge, Vert, Bleu, chacun de 00 (rien) à FF (maximum). #FF0000 = rouge seul. #FFFF00 = rouge + vert = jaune. #808080 = la moitié de tout = gris. Forme courte : #f00.
  • rgb(255,0,0) : la même chose en décimal, de 0 à 255.
  • rgba(0,0,0,0.5) : le 4e nombre est l’opacité, de 0 (invisible) à 1 (opaque). Ici : noir à 50 %.
  • Unités absolues (px, pt, cm, mm) : taille fixe. Unités relatives : em et % dépendent du parent ; rem de la racine ; vw/vh de la fenêtre.

Pourquoi

  • Les unités relatives s’adaptent à l’écran et aux réglages de police de l’utilisateur : on les préfère pour la mise en page.
Pièges :
  • color: ff0000 → il manque le #.
  • margin: 10 → l’unité est obligatoire (10px) ; « 16 px » avec un espace est faux aussi.
  • Les em imbriqués se multiplient : parent 1.5em (24px), enfant 1.5em = 36px, pas 24px.

p {
  font-family: Georgia, "Times New Roman", serif;
  font-size: 18px;
  font-weight: bold;
  text-transform: uppercase;
  line-height: 1.5;
}

italic · underline · line-through · small-caps · capitalize each word

How it works

  • font-family: a stack. The browser tries each font left to right and uses the first one installed. The last must be a generic family (serif, sans-serif, monospace). A name with a space needs quotes.
  • font-size: 18px: size of the letters. font-weight = bold; font-style = italic.
  • text-transform changes the case without touching the HTML (uppercase, lowercase, capitalize).
  • line-height: 1.5: line spacing = 1.5 × the font size. Improves readability.
  • text-align aligns the CONTENT (left, center, right, justify). text-decoration: underline, line-through, none (removes the underline of links).
Traps: small capitals = font-variant: small-caps (not font-style). Write underline, not “underlined”.

Comment ça marche

  • font-family : une pile. Le navigateur essaie chaque police de gauche à droite et prend la première installée. La dernière doit être une famille générique (serif, sans-serif, monospace). Un nom avec espace prend des guillemets.
  • font-size: 18px : taille des lettres. font-weight = gras ; font-style = italique.
  • text-transform change la casse sans toucher au HTML (uppercase, lowercase, capitalize).
  • line-height: 1.5 : interligne = 1,5 × la taille de police. Améliore la lisibilité.
  • text-align aligne le CONTENU (left, center, right, justify). text-decoration : underline, line-through, none (supprime le soulignement des liens).
Pièges : les petites capitales = font-variant: small-caps (pas font-style). Écrire underline, pas « underlined ».

5. The cascade: when 2 rules fightLa cascade : quand 2 règles se battent

li { color: black; }
.carte li { color: blue; }
li.star { color: orange; }
#bo li.star { color: red; }
  • li
  • .carte li
  • .carte li.star
  • #bo .carte li.star

Weights

Calculating for the 4 rules above

  • li → 1 point (1 element).
  • .carte li → 10 + 1 = 11.
  • li.star → 1 + 10 = 11 → tie with the previous one: the last written wins (orange).
  • #bo li.star → 100 + 1 + 10 = 111 → wins over all: the last li is red.

Method (4 steps)

  • 1) List the rules that aim at the element. 2) Add the weights. 3) Heaviest wins. 4) Tie → last written wins. Inheritance is the weakest of all.
  • Inherited: color, font-*, text-align, line-height, list-style. Not inherited: margin, padding, border, background, width, height, position, display.
Trap: order only matters on a tie: a #id rule written BEFORE a p rule still wins. Avoid !important (it beats everything and makes the code hard to fix).

Calcul pour les 4 règles ci-dessus

Méthode (4 étapes)

  • 1) Lister les règles qui visent l’élément. 2) Additionner les poids. 3) Le plus lourd gagne. 4) Égalité → le dernier écrit gagne. L’héritage est le plus faible de tous.
  • Hérités : color, font-*, text-align, line-height, list-style. Non hérités : margin, padding, border, background, width, height, position, display.
Piège : l’ordre ne compte qu’en cas d’égalité : une règle #id écrite AVANT une règle p gagne quand même. Éviter !important (il bat tout et rend le code difficile à corriger).

6. The box modelLe modèle de boîte

.box {
  width: 300px;
  padding: 20px;
  border: 4px solid #8b4513;
  margin: 0 auto;
  box-sizing: border-box;
}
margin
border
padding
content

How it works

  • Every element is a box of 4 layers, from inside to outside: content → padding → border → margin.
  • padding: 20px: space INSIDE the border, coloured by the background.
  • border: 4px solid #8b4513: width + style + colour. No style = no border.
  • margin: 0 auto: 0 above and below, auto left and right = the block is centred (it needs a width).
  • box-sizing: border-box: width now INCLUDES padding and border, so the box stays 300px wide.

Calculation

  • Without border-box: visible width = 300 + 2×20 (padding) + 2×4 (border) = 348px (+ 2×margin for the space used).

Shorthands (clockwise: Top Right Bottom Left)

  • margin: 10px → 4 sides.
  • margin: 10px 20px → top-bottom | left-right.
  • margin: 10px 20px 30px → top | left-right | bottom.
  • margin: 10px 20px 30px 40px → top right bottom left.

Margin vs padding

  • Margin: outside the border, transparent, negative values allowed. Padding: inside, coloured, negative forbidden. To “air” the content, use padding.
Traps: border: 3px blue shows nothing. width/height have no effect on inline elements (span, a). For responsive images: img { max-width: 100%; }.

Comment ça marche

  • Chaque élément est une boîte de 4 couches, de l’intérieur vers l’extérieur : contenu → padding → bordure → margin.
  • padding: 20px : espace À L’INTÉRIEUR de la bordure, coloré par le fond.
  • border: 4px solid #8b4513 : épaisseur + style + couleur. Sans style = pas de bordure.
  • margin: 0 auto : 0 en haut et en bas, auto à gauche et à droite = le bloc est centré (il faut un width).
  • box-sizing: border-box : width INCLUT maintenant padding et bordure, donc la boîte reste large de 300px.

Calcul

  • Sans border-box : largeur visible = 300 + 2×20 (padding) + 2×4 (bordure) = 348px (+ 2×margin pour la place occupée).

Raccourcis (sens horaire : Haut Droite Bas Gauche)

  • margin: 10px → les 4 côtés.
  • margin: 10px 20px → haut-bas | gauche-droite.
  • margin: 10px 20px 30px → haut | gauche-droite | bas.
  • margin: 10px 20px 30px 40px → haut droite bas gauche.

Margin ou padding ?

  • Margin : à l’extérieur de la bordure, transparente, valeurs négatives permises. Padding : à l’intérieur, colorée, négatif interdit. Pour « aérer » le contenu, utiliser padding.
Pièges : border: 3px blue n’affiche rien. width/height sans effet sur les éléments inline (span, a). Images adaptatives : img { max-width: 100%; }.

7. Borders, shadows, backgroundsBordures, ombres, arrière-plans

.a { border: 3px solid #8b4513; border-radius: 10px; box-shadow: 6px 6px 4px gray; }
.b { border: 3px dashed #8b4513; }
.c { border-radius: 50%; background-color: #8b4513; }
.d { background: white url('a.png') no-repeat right bottom; }

How it works

  • border-radius: 10px rounds the corners (4 values: top-left, top-right, bottom-right, bottom-left). 50 % on a square = circle.
  • box-shadow: 6px 6px 4px gray = x offset, y offset, blur, colour: the shadow is 6px right, 6px down, softened by 4px.
  • Border styles: solid, dotted, dashed, double, groove, ridge, inset, outset, none.
  • background shorthand: colour + url('image') + repeat + position. Here: white background, image once, in the bottom right corner (circle in the 4th box).
  • background-repeat: repeat (default), repeat-x (horizontal), repeat-y (vertical), no-repeat. background-size: cover, contain. background-attachment: fixed keeps the image still when scrolling.
Traps: color = TEXT colour, background-color = BACKGROUND colour. Write url('a.png'), not url (a.png) and not a.png alone.

Comment ça marche

  • border-radius: 10px arrondit les coins (4 valeurs : haut-gauche, haut-droite, bas-droite, bas-gauche). 50 % sur un carré = cercle.
  • box-shadow: 6px 6px 4px gray = décalage x, décalage y, flou, couleur : l’ombre est à 6px à droite, 6px en bas, adoucie de 4px.
  • Styles de bordure : solid, dotted, dashed, double, groove, ridge, inset, outset, none.
  • Raccourci background : couleur + url('image') + répétition + position. Ici : fond blanc, image une seule fois, dans le coin en bas à droite (le cercle de la 4e boîte).
  • background-repeat : repeat (défaut), repeat-x (horizontal), repeat-y (vertical), no-repeat. background-size : cover, contain. background-attachment: fixed garde l’image immobile au défilement.
Pièges : color = couleur du TEXTE, background-color = couleur du FOND. Écrire url('a.png'), pas url (a.png) et pas a.png seul.

8. A menu from a listUn menu à partir d’une liste

.mn { list-style-type: none; margin: 0; padding: 0; }
.mn li { display: inline-block; }
.mn a { display: block; padding: 10px 15px; background-color: #4b2e1e;
        color: white; text-decoration: none; }
.mn a:hover { background-color: orange; }
  • 1
  • 2
  • 3

How it works, rule by rule

  • Rule 1: list-style-type: none removes the bullets; margin: 0; padding: 0 removes the default left indent of the list.
  • Rule 2: inline-block puts the li side by side (like inline) while still accepting width, height and margin.
  • Rule 3: a link is inline, so padding and width would not work well. display: block makes the WHOLE rectangle clickable, with padding, a dark background, white text and no underline.
  • Rule 4: a:hover changes the colour when the mouse is over: hover the buttons above.

Why

  • A menu is semantically a list of links: this recipe keeps the HTML clean and the style in CSS.

Comment ça marche, règle par règle

  • Règle 1 : list-style-type: none supprime les puces ; margin: 0; padding: 0 supprime le retrait gauche par défaut de la liste.
  • Règle 2 : inline-block place les li côte à côte (comme inline) tout en acceptant width, height et margin.
  • Règle 3 : un lien est inline, donc padding et width ne marcheraient pas bien. display: block rend TOUT le rectangle cliquable, avec padding, fond foncé, texte blanc et sans soulignement.
  • Règle 4 : a:hover change la couleur quand la souris est dessus : survolez les boutons ci-dessus.

Pourquoi

  • Un menu est sémantiquement une liste de liens : cette recette garde le HTML propre et le style dans le CSS.

10. Display and positionDisplay et position

.carte { position: relative; }
.badge { position: absolute; top: 10px; right: 10px; }
.carte.badge

How it works

  • .carte { position: relative }: the card stays in the flow but becomes the reference for its children.
  • .badge { position: absolute }: leaves the flow (frees its place) and is placed relative to the nearest positioned ancestor, here .carte.
  • top: 10px; right: 10px: 10px from the top edge and 10px from the right edge of the card → corner badge.

Display

  • block: one per line, takes the whole width (div, p, h1-h6, ul, li, table, header, nav, section, footer).
  • inline: follows the text, size of its content, width/height ignored (span, a, em, strong, img).
  • inline-block: inline BUT accepts width, height, margin (menus).

11. Float / clear

.photo { float: left; width: 90px; }
footer { clear: both; }
Lorem ipsum dolor sit amet, consectetur adipiscing elit, sed do eiusmod tempor incididunt ut labore et dolore magna aliqua.Lorem ipsum dolor sit amet, consectetur adipiscing elit, sed do eiusmod tempor incididunt ut labore et dolore magna aliqua.

How it works

  • float: left pulls the element out to the left; the following text wraps around it, like a photo in a newspaper.
  • clear: both, set on the element that must go below (the footer), stops it from sliding next to the floats.
  • Floats sit side by side while the real widths fit: 652 + 102 = 754 < 800 → OK; 652 + 602 = 1254 > 800 → the second goes under.
  • A container holding only floats collapses to height 0: add clear: both after, or overflow: hidden on the container.
Trap: clear is NOT the opposite of float and is never set on the floating element.

Comment ça marche

  • float: left envoie l’élément à gauche ; le texte suivant s’enroule autour, comme une photo dans un journal.
  • clear: both, mis sur l’élément qui doit passer dessous (le footer), l’empêche de se glisser à côté des floats.
  • Les floats restent côte à côte tant que les largeurs réelles tiennent : 652 + 102 = 754 < 800 → OK ; 652 + 602 = 1254 > 800 → le second passe dessous.
  • Un conteneur ne contenant que des floats s’effondre à hauteur 0 : ajouter clear: both après, ou overflow: hidden sur le conteneur.
Piège : clear n’est PAS le contraire de float et ne se met jamais sur l’élément flottant.

How it works

  • display: flex goes on the PARENT: its direct children line up by themselves in a row.
  • justify-content distributes along the MAIN axis (the row): flex-start, flex-end, center, space-between (space only BETWEEN items), space-around (space AROUND each item).
  • align-items aligns on the CROSS axis (vertical in a row): stretch (default), flex-start, flex-end, center, baseline. align-self does it for ONE item.
  • flex: 1 / flex: 3: the items share the free space in proportion → columns of 1/4 and 3/4.
  • flex-direction: row (default), column, row-reverse, column-reverse. flex-wrap: wrap goes to the next line when full.

Why

  • Flexbox is the modern layout: navigation bars, columns, perfect centring (center + center). Float is only for wrapping text around an image.
Trick: Justify = Just the main axis (the row); Align-items = the Across axis.
Trap: with flex-direction: column the axes swap: justify-content then works vertically.

Comment ça marche

  • display: flex se met sur le PARENT : ses enfants directs s’alignent tout seuls en ligne.
  • justify-content répartit sur l’axe PRINCIPAL (la ligne) : flex-start, flex-end, center, space-between (espace seulement ENTRE les éléments), space-around (espace AUTOUR de chaque élément).
  • align-items aligne sur l’axe TRANSVERSAL (vertical dans une ligne) : stretch (défaut), flex-start, flex-end, center, baseline. align-self le fait pour UN seul élément.
  • flex: 1 / flex: 3 : les éléments se partagent l’espace libre en proportion → colonnes de 1/4 et 3/4.
  • flex-direction : row (défaut), column, row-reverse, column-reverse. flex-wrap: wrap passe à la ligne suivante quand c’est plein.

Pourquoi

  • Flexbox est la mise en page moderne : barres de navigation, colonnes, centrage parfait (center + center). Float ne sert qu’à habiller une image de texte.
Astuce : Justify = l’axe principal (la ligne) ; Align-items = l’axe transversal.
Piège : avec flex-direction: column les axes s’inversent : justify-content agit alors verticalement.

13. Clean code and quick wrong / rightCode propre et faux / juste

  • One external file (style.css): no inline styles, no !important.
  • One declaration per line, indented by 2 spaces, always ending with “;”.
  • Group shared styles (h1, h2, h3 { … }) and use classes instead of repeating lines.
  • Classes over ids: an id weighs 100 and is unique; a class weighs 10 and is reusable. Name by meaning (.carte), not by look.
  • Short selectors: avoid #boissons ul li a; heavy selectors are hard to override.
  • Order: base (*, body) → header/nav → layout → components → table → footer, with a comment title per block.
  • Shorthands and relative units; reset once: * { box-sizing: border-box; } body { margin: 0; }.
  • Test: change one value and look; the inspector (F12) shows which rule wins.
